1. Propósito y alcance

Desarrollar módulos Android del CRM Codivis para registrar cuentas, autenticar usuarios y administrar sus clientes desde un teléfono. Esta implementación funciona sin conexión mediante SQLite privado. Cada cuenta accede únicamente a sus clientes. No sincroniza con la API web de la Guía 7; es una implementación móvil local, con acceso a datos documentado y sustituible mediante la interfaz Repositorio.

El paquete com.codivis.crm.movil es independiente de la primera aplicación de EV01. Ambas se pueden instalar juntas. No hay cuentas ni clientes precargados.

3. Metodología y arquitectura

Se empleó un desarrollo incremental: definición de alcance y validaciones; implementación de dominio y persistencia; construcción de pantallas; pruebas automatizadas; compilación y documentación. No se atribuyen reuniones o ceremonias de equipo que no se hayan realizado. Los diagramas siguientes describen el código de esta entrega.

CodivisApp compone las dependencias. Sesion conserva el identificador y nombre en preferencias privadas. Se aplica Repository para separar reglas y acceso a datos, composición de dependencias y reutilización de formularios. Las Activities coordinan eventos; las reglas no dependen de los widgets.

4. Implementación de módulos

MóduloArchivos y comportamiento
AutenticaciónAutenticacionService valida datos y duplicados; PasswordHasher produce y verifica hashes. RegistroActivity y LoginActivity muestran errores sin descartar el formulario.
ClientesClienteService concentra validaciones y propiedad. ClientesActivity lista y busca; ClienteDialog reutiliza creación y edición; eliminación con confirmación.
PersistenciaBaseDatos crea tablas y activa claves foráneas. SQLiteRepositorio utiliza argumentos enlazados y filtros de propietario, y cierra cursores.
SesiónSesion guarda solo id y nombre. No almacena contraseña ni hash en preferencias. BaseActivity exige sesión para la pantalla de clientes.
Componentes visualesUi comparte campos, botones, mensajes y espaciados. Se utilizan widgets del framework Android, sin librerías externas de interfaz.

Datos y configuración de servidor

No requiere servidor, puerto, credenciales de base de datos externa ni permiso de Internet. SQLiteOpenHelper administra codivis.db, versión 1, en el almacenamiento privado de la aplicación. usuarios contiene id, nombre único sin distinguir mayúsculas y clave_hash. clientes contiene id, usuario_id, nombre, correo y teléfono, con clave foránea y restricción única (usuario_id, correo). Se indexa el propietario.

La sesión permanece al cerrar y volver a abrir hasta pulsar Cerrar sesión. Desinstalar o borrar los datos elimina las cuentas locales. El APK no ofrece recuperación de contraseña ni sincronización. Para versiones futuras se deben implementar migraciones explícitas; el código no elimina tablas silenciosamente ante cambios de versión.

Comprobación manual pendiente en Android

  1. Instalar el APK y abrir Codivis Móvil. Crear el usuario pedro con una contraseña propia de al menos 8 caracteres.
  2. Iniciar sesión; crear un cliente con nombre, correo y teléfono opcional.
  3. Buscarlo, editarlo y comprobar persistencia al reabrir.
  4. Cerrar sesión, registrar luis y comprobar que no ve los clientes de pedro.
  5. Volver a pedro, eliminar el cliente con confirmación y cerrar sesión.

7. Apertura, compilación e instalación

  1. Abrir esta carpeta completa en Android Studio (contiene settings.gradle). Instalar SDK 35 y Build Tools 36.0.0. Seleccionar un JDK compatible con Gradle 9.1.
  2. Permitir que Android Studio configure local.properties con la ruta del SDK del equipo. Ese archivo no se distribuye.
  3. Ejecutar gradlew.bat testDebugUnitTest assembleDebug. La primera ejecución requiere Internet para descargar herramientas y dependencias.
  4. El resultado se genera en app/build/outputs/apk/debug/app-debug.apk. Una copia se entrega en apk/Codivis-Movil-GA8-AA2-EV02.apk.
  5. Copiar el APK al teléfono, abrirlo y permitir la instalación desde esa fuente si Android lo solicita. Alternativamente, con depuración USB autorizada: adb install -r apk/Codivis-Movil-GA8-AA2-EV02.apk.
